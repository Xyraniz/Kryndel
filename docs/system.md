# System integration guide

Kryndel exposes a small typed system boundary rather than a general host-language escape hatch. The stable registry includes `fs_read_text`, `fs_write_text`, and `env_get` in addition to the bounded thread and channel primitives.

`fs_read_text(path)` reads exact bytes, validates UTF-8, closes the stream, and returns `Result[String, String]`. `fs_write_text(path, text)` writes the exact UTF-8 bytes carried by the String value, closes the stream, and returns `Result[Nil, String]`. Embedded NUL bytes in paths are rejected so the source-level path cannot be silently truncated by a host filesystem API. File content may contain NUL bytes only when it is valid UTF-8 text; its length remains explicit and lossless.

`env_get(name)` returns `some(value)` for a present, valid UTF-8 environment variable and `none` when the variable is absent. Names containing NUL are runtime errors because host environment APIs use terminated strings; invalid UTF-8 environment values are rejected rather than becoming invalid `String` values. The API does not mutate the process environment, execute commands, or expose file descriptors.

Modules remain source-relative and reject absolute paths, parent traversal, artifacts, missing files, duplicate exports, and cycles. Filesystem APIs use trusted local mode by default. `--restricted ROOT` enables restricted mode that rejects absolute paths and `..`, checks every existing component with `Lstat`, rejects symlink components, confines destination parents to the root, writes through a temporary file, and atomically replaces only after revalidation. The Go executable uses no C compiler or external runtime. `kry doctor` verifies executable capabilities, limits, and builtin-registry completeness.

Source and artifact inputs are bounded by safe defaults of 16 MiB and 64 MiB respectively; `--max-source` and `--max-artifact` allow a caller to choose stricter per-invocation limits. The same execution context applies instruction, wall-clock, call-depth, memory, collection, channel, worker, and output budgets. Resource failures produce categorized diagnostics before parsing or execution. Process creation, sockets, terminal control, signals, raw pointers, dynamic libraries, and FFI are outside the stable source API. Any future addition must specify type signatures, error values, ownership and cleanup, path or capability boundaries, platform support, deterministic tests, and documentation before implementation is accepted.
